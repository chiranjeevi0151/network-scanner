# # 🛰️ Network Scanner - Python Cybersecurity Tool

A beginner-friendly Python script to scan a local IP range and detect live devices using ICMP (ping).

## 🔧 Features
- Scans an entire local subnet (e.g., 192.168.1.x)
- Pings each device to check if it's active
- Displays active devices in real-time

## 💻 Tech Used
- Python
- OS Module
- ICMP Ping (platform independent)
